# 8086 Assembly Language Programs

This repository contains Assembly Language programs developed using the EMU8086 emulator.

## Division Program

The `division.asm` program performs division of two single-digit numbers using 8086 Assembly Language.

### Features
- Takes dividend and divisor as user input.
- Performs integer division.
- Displays the quotient.
- Handles division by zero.
- Uses DOS interrupts for input and output.

### Technologies Used
- 8086 Assembly Language
- EMU8086 Emulator
- DOS Interrupt 21h

### Example Output

```text
Enter dividend: 8
Enter divisor: 5
Your quotient: 1
```

### How to Run
1. Open EMU8086.
2. Open the `division.asm` file.
3. Compile the program.
4. Run it using the emulator.
5. Enter the dividend and divisor.

### Note
This is a beginner-level Assembly Language program for learning basic arithmetic operations and DOS interrupts.
